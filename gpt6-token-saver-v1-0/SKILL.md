# GPT6省token工具v1.0

- 仅允许 `gpt-6-astra` 与 `gpt-5.6-sol`；禁止 Terra、Luna 及其他模型，不使用可能改指向的模型别名。
- 默认推理强度：Astra=`medium`，Sol=`medium`。用户为两者分别指定的强度优先；配置中的明确选择同样有效。未指定的一方保持默认，不自动升档。
- Astra 只做需求理解、规划、架构决策、任务拆分和最终验收；仓库搜索/读取、资料调查、编码、前端实现、命令执行、调试、测试、重构和技术审查全部交给 Sol。验收依据 Sol 返回的证据；缺证据时交回 Sol 补查，Astra 不自行读仓库或运行测试。
- 使用当前任务的原生子代理工具，创建时显式指定 `model="gpt-5.6-sol"` 与选定推理强度。若工具提供 `fork_turns`，使用 `"none"` 并传递最小必要上下文；不要全历史复制。按实际工具 schema 调用，不虚构参数。
- 默认复用一个 Sol 执行代理；仅对确实独立、值得并行的子任务增加 Sol。委派说明目标、工作路径、约束、相关决定和验收条件；Sol 直接执行，不再递归委派。重大架构取舍交回 Astra。
- Sol 只回传结论、变更路径、必要差异、验证结果与未解决问题；不回传整文件或长日志。Astra 按验收条件决定完成或继续修正，不重复 Sol 的工作。
- 主代理不是 Astra、Sol 不可用、无法指定模型/强度或委派受限时，明确说明阻塞，不静默换模型或由 Astra 接管执行。Skill 无法改变已运行主代理的模型/推理强度；用户须在界面或启动参数中设置。Sol 子代理收到本 Skill 时只执行已分配工作。
